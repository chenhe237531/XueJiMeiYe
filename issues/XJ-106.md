## 背景

- 本轮要新增 5 个页面：接力棒、徽章墙、盲盒、六维周报、门店集章册，所属分包均已存在。
- `src/pages.json` 是单文件，被 5 个 Issue 同时编辑会产生必然的合并冲突。

## 范围与实现要点

1. 在 `pages.json` 对应分包下登记 5 条路由：`pkg-family/relay`、`pkg-me/achievements`、`pkg-game/box`、`pkg-archive/weekly`、`pkg-module/stamps`。
2. 创建 5 个占位页：`XNav` + 空状态提示 + `definePage()` 配置（`navigationStyle: custom`，标题按设计文档）。
3. 占位页根节点必须绑 `:class="xj.pageClass"`（全站约定，动效档位靠它下发）。
4. 登记完成后，本 Issue 成为 `pages.json` 的唯一可写方；后续需要改路由的 Issue 必须在本 Issue 留言申请。

## 验收标准

- [ ] 5 条新路由可在开发者工具中通过 `uni.navigateTo` 跳转并正常显示占位内容。
- [ ] 分包根名称未变（`pkg-family` / `pkg-me` / `pkg-game` / `pkg-archive` / `pkg-module`）。
- [ ] 构建产物包含 5 个新页面，且 `app.json` 的 `subPackages` 结构正确。
- [ ] 页面上能看到 `mo-` 档位 class 已生效（不是裸页面）。

## 禁止事项

- ⛔ 不要顺手调整其他页面的路由或分包结构。
- ⛔ 不要在本 Issue 里实现页面内容——各页面由后续专属 Issue 负责。
