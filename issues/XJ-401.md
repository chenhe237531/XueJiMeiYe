## 背景

- 现有 `pkg-points/checkin.vue` 仅 69 行，是一个简单打卡按钮，没有日历、没有连签激励、没有里程碑。
- 后端已支持扩展字段（XJ-302 提供 `streakDays` 与 `monthSignedDates`）。

## 范围与实现要点

1. 顶部连签卡：金色渐变；左「已连续签到 N 天」大数字，右「本月已签 M 天」。
2. 月历网格（`CalendarGrid.vue`）：7 列；已签 = 金底实心圆；今日 = 白底 + 2px 金描边；过去未签 = 灰底；未来 = 浅灰。
3. 7 格奖励轨道（`RewardTrack.vue`）：+2 / +2 / +3 / +3 / +5 / +5 / 金蛋；金蛋格虚线描边 + 蛋形图形。
4. 「今日还可做」三项任务（睡眠 / 运动 / 喝水），已完成降级为灰字 + `✓`。
5. 里程碑：连签 7 / 14 / 30 天解锁金蛋（15 积分 + 门店体验券）。
6. 动效：签到成功 `+5` 上浮淡出 600ms；金蛋格 `scale` 脉冲（`mo-off` 下静止）。
7. 漏签只显示「从今天继续」，不做中断惩罚提示。

## 验收标准

- [x] 四种日期状态（已签 / 今日 / 过去未签 / 未来）在同一屏内视觉可辨。
- [x] 连签天数与本月已签天数与后端数据一致。
- [x] 签到成功有 `+5` 上浮动画，乐龄下无动画但仍清晰显示积分变化。
- [x] 金蛋格在未解锁 / 已解锁两态下样式不同。
- [x] 与 XJ-401 关联的入口（首页签到条）跳转可达。

**实现**（只动 files_own：`checkin.vue` 重写 69 → 约 130 行 + 新建 `components/points/CalendarGrid.vue` + 新建 `components/points/RewardTrack.vue`）：

1. **顶部连签卡**：金色渐变底 + `--on-brand` 文字；左「已连续签到 N 天」大数字、右「本月已签 M 天」；CSS 蛋形装饰不依赖图形资源。
2. **月历网格 CalendarGrid**：周一开头；四态 s-signed（金渐变底）/ s-today（白底 2px 金描边）/ s-miss（灰底）/ s-future（浅灰字）+ 图例行。点击用事件委托——容器单个 `@tap` + 每格 `data-date` dataset，编译产物 bindtap 仅 1 处，杜绝 30+ 个独立监听。
3. **7 格奖励轨道 RewardTrack**：+2 / +2 / +3 / +3 / +5 / +5 + 金蛋格；`lit = streak <= 0 ? 0 : ((streak - 1) % 7) + 1`。金蛋两态：未解锁虚线描边线稿蛋 / 已解锁金渐变蛋 + `egg-pulse` 脉冲（scale 1→1.12，2.4s 循环，`getTier() !== 'off'` 才播）。里程碑 chips：7 天首枚金蛋 / 14 天再接再厉蛋 / 30 天满月金蛋（15 积分 + 门店体验券）。金蛋用纯 CSS 蛋形（uno.config 不在 files_own，不新增 safelist）。
4. **「今日还可做」三项**（睡眠 / 运动 / 喝水）：已完成降级为灰字 + `✓` tag、按钮 ghost 样式、无 +N 气泡。
5. **+N 上浮动效**（D8）：float-up 600ms（translateY(-30px) + 淡出），仅积分 > 0 时触发；乐龄 mo-off 不播动画，toast「打卡成功 +N 积分」清晰传达变化。
6. **温和文案**：漏签格点击提示「漏签不焦虑，从今天继续就好」——无倒计时、无中断惩罚，连签中断不清空成就。
