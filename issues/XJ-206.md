## 背景

- 项目无图表库，图表是手写 SVG：`xj/utils.ts` 的 `radarSvg` / `lineSvg` 生成的是**静态字符串**，无法交互、无法做生长动画。
- 档案页现有趋势折线是一次性渲染的图片，点按无反馈。

## 范围与实现要点

1. `XIndexRing.vue`：SVG 圆环，支持 0~100 指数、中心数字、可选数字滚动；`stroke-dashoffset` 生长动画 800ms。
2. `XTrendChart.vue`：渐变面积曲线 + 可点按数据点 + 提示气泡；数据以 props 传入（`series` / `labels` / `unit`）。
3. 两组件均只动 `transform` / `opacity` / `stroke-dashoffset`，不使用 `width` 过渡。
4. `mo-off` 档位下直接呈现最终态（生长动画跳过）。
5. 组件不自行发请求，数据由页面注入（保持可复用与可测）。

## 验收标准

- [ ] 两组件可独立传值渲染（提供独立自检方式，如临时页面或注释中的用法示例）。
- [ ] 生长动画在 `mo-full` 下播放、在 `mo-off` 下直接呈现（录屏对比）。
- [ ] 点按数据点显示对应数值，连续点按无错位。
- [ ] 指数环数字滚动时长与设计规范一致（≤600ms）。

## 禁止事项

- ⛔ 不要引入图表库（包体积与小程序兼容性双重风险）。
- ⛔ 不要在组件内硬编码业务色，颜色走令牌或 props。
- ⛔ 不要修改 `xj/utils.ts` 的既有导出（其他页面仍在使用 `radarSvg` / `lineSvg`）。
