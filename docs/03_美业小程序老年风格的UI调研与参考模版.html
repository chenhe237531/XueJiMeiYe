美业小程序 UI 调研与参考模版

面向「雪姬美业 · 六维健康平台」的界面升级调研：盘点市面美业相关小程序的设计风格与页面结构，结合乐龄女性用户、健康测评 + 门店养护的产品定位，给出三套可参考的设计模版方向与逐页借鉴清单。

调研时间 2026-10 覆盖 4 类 · 10+ 产品 含适老化规范对照

1市面产品调研总览

美业相关小程序可分四类。雪姬横跨「健康管理」与「美业服务」两界，参考对象也按这个双定位选取。

美
美团丽人
综合到店平台 · 行业事实标准
设计风格高饱和品牌黄 + 黑字，高对比、高信息密度；白卡片 + 灰底；价格用橙红锚点。
页面结构门店页 = 头图 + 团购卡片流 + 评价信任区；金刚区分类入口；底部一键预约。
对雪姬的借鉴：雪姬现有设计令牌本就向美团靠拢（品牌黄 #FFD100、圆角 12/8/4），方向正确——继续深化「门店项目卡片 + 价格锚点 + 评价信任」三件套，降低乐龄用户的认知成本（她们已在美团上见过这套语言）。
河
河狸家
上门美业 O2O · 老牌标杆
设计风格低饱和暖色系，柔粉为主；入口极简，图标+大字说明，饱和度压低。
页面结构信息层级只有 2–3 层；「预约」按钮居中放大高亮；信任体系前置（审核标识、九大流程保障、监督电话）。
对雪姬的借鉴：①「预约/测评」主行动按钮要在 tab 或页面固定位置放大，乐龄用户不会去找藏在角落的入口；② 陌生人服务 = 信任先行，医院转介、门店养护页应把资质、流程保障做成显眼的信任徽章区，而不是一行小字。
氧
新氧（新氧魔镜）
医美平台 · AI 测肤代表
设计风格粉白轻医美风 + 社区日记流；魔镜 AI 报告用深色底 + 彩色数据，突出「科技感」。
魔镜功能拍照 → AI 多维度分析（出油、毛孔、细纹、光滑度…）→ 生成评分报告 + 改善建议 + 项目推荐，形成「测评 → 方案 → 转化」闭环。
对雪姬的借鉴：雪姬「魔镜」是最接近新氧魔镜的功能。可参考其「报告即转化」结构：六维测评结果页 = 雷达总览 + 维度打分卡 + 每维度一句人话解读 + 门店养护方案 CTA。报告要「好看到愿意给女儿看」，才有自传播。
S
美业 SaaS 模版类
卓旭 / 肌遇 / 码云数智等
风格定位行业公认三档：轻美容 = 柔粉+香槟金+奶白；高端抗衰 = 黑金+米白轻奢；养生 SPA = 墨绿+原木自然。
标准页面架构首页（Banner + 金刚区 + 热门瀑布流 + 客评）→ 服务列表（分类 Tab + 筛选 + 卡片）→ 详情（款式/技师/日历时段）→ 预约 5 步流 → 会员中心（等级徽章 + 权益 + 储值积分）。
对雪姬的借鉴：雪姬的页面骨架已对齐这套标准（tab 4 页 + 分包）。真正的差距在「养生 SPA 档」的视觉质感：墨绿 + 原木 + 暖白最贴合「乐龄 + 健康养护」的心智，比继续抄美团黄更适合雪姬的健康主业。
健
健康管理类
美年 / 平安好医生 / 健康评估原型
设计风格浅灰蓝底 + 白卡；状态色严格编码：绿=正常、橙=临界、红=异常；核心是数据可视化而非氛围。
报告可视化雷达图（多维评分）、折线图（指标趋势）、仪表盘（偏离程度）、环形图（构成占比），配合通俗文案 + 行动建议。
对雪姬的借鉴：六维测评结果、指标趋势页应完全采用这套「体检报告语言」：雷达图 + 绿橙红状态色 + 每个异常指标跟一句「这意味着什么 + 该做什么」。红色仅用于紧急就医（雪姬已有 --care/--alert 令牌，语义正确）。
龄
适老化设计规范
工信部 WCA / 微信长辈就医指引
核心硬指标适老版正文字号 ≥ 18pt；行距 ≥ 1.3 倍；对比度 ≥ 4.5:1；可点击区域 ≥ 60×60pt；关闭按钮 ≥ 44×44pt；禁止广告与诱导按钮。
交互原则首页零思考（只留核心功能）、流程无分支、图标必须带文字标签、关键节点语音播报、支持子女代管代收消息（雪姬已有 pkg-family，是天然优势）。
对雪姬的借鉴：乐龄模式不能只是「字号放大」。对照规范自查：elder 模式正文字号 17px 是否提到 18pt 级别、按钮高度 48px 是否达到 60pt 热区、家属代办链路是否在适老版中优先露出。「家人帮我看」应成为一等公民入口。

2三套可参考的设计模版方向

结合雪姬「健康为本、美业为用、乐龄为主」的定位，给出三套方向。均为首页示意，可与现有 CSS 变量体系平滑映射。

方向 A · 效率黄 现有体系深化
沿用 #FFD100 美团语言：高对比、大按钮、价格锚点。优点是乐龄用户对美团式界面有肌肉记忆、转化路径短；缺点是「外卖感」强，健康信任感弱。
方向 B · 养生绿 推荐 · 最贴定位
美业 SaaS「养生 SPA 档」：墨绿 #1F6E68 主色（雪姬已有 --care 令牌）+ 原木暖白。首页从「卖项目」改为「今日健康」：健康分 + 今日安排 + 门店服务，健康信任感与乐龄友好度最高。
方向 C · 夜色金 差异化 · 已有雏形
雪姬代码里已有 night（A 级会员夜版）逻辑。可发展为「高端会员专属皮肤」：深底 + 金 #D2B47A 尊贵感，把会员权益、魔镜陪伴、定制方案做成奢侈品化叙事。作为 A/B 混合方向而非全局替换。
推荐策略：方向 B 为全局主风格（健康信任 + 乐龄友好），方向 A 的「美团式门店卡片」保留在门店项目 / 体检券等强转化页，方向 C 作为 A 级会员的专属夜版皮肤。三者共用同一套布局骨架与组件，只切换设计令牌——现有 CSS 变量架构（page 令牌 + .xj + .elder）完全支撑这种做法。

3页面级参考模版清单

把调研结论落到雪姬的每一类页面上：参考谁、怎么改。

雪姬页面参考对象具体做法
首页 方向 B 养生 SPA 档 顶部问候 + 健康分大卡（环形进度）；金刚区只留 4 个大图标入口（测评 / 体检 / 养护 / 家人），图标必须配文字；今日安排卡承接「养护方案」落地感；门店卡片沿用美团式价格锚点做转化。Banner 减弱为一条活动横幅，不再占首屏。
六维测评（intro / question） 微信长辈就医 · 适老流程 答题页一屏一题、大选项卡（热区 ≥ 60pt）、进度条粗体可视；避免分支和弹窗；「坐站小测」「单腿站立」用图示分步引导（≥3 步图），完成后语音/震动反馈。文案口语化：「测平衡」而非「静态平衡功能评估」。
测评结果 / 指标趋势 新氧魔镜报告 + 体检可视化研究 雷达图总览 + 六张维度评分卡；绿 / 橙 / 红状态色与雪姬 --care / --hint / --alert 令牌对齐；每个维度三行结构：「得了几分 → 一句人话解读 → 建议做什么」；趋势页用粗折线 + 异常点标注；底部固定「生成我的养护方案」CTA，报告即转化。
魔镜（AI 陪伴） 新氧魔镜入口设计 新氧把魔镜放在首页左上角一级入口，认知成本低。雪姬魔镜已占一个 tab，可在对话界面加「头像拟人 + 大字号气泡 + 常用问题按钮组」（免打字输入，适老化关键）；记忆卡片（小镜记得的事）用轻收藏卡样式。
门店项目 / 预约 美团丽人 + 河狸家信任区 项目卡片 = 实拍图 + 名称 + 时长 + 星标评分 + 橙红价格（--price 令牌语义正确）；门店页头部加「信任徽章带」：卫生许可、技师资质、免费接送、到店保障（学河狸家把审核与保障前置）；时段选择用大格日历 + 余位提示「还剩 2 个时段」制造稀缺。
体检预约 / 体检券 SaaS 模版券包页 + 美团券样式 券用左右撕票结构（左侧金额大字、右侧使用条件），临期券红标提醒（美业 SaaS 标配）；接送预约独立成一步而非表单里的一个字段；合作医院信息 = logo + 等级 + 距离 + 一句话，弱化销售感、强化转介的权威感。
健康档案 / 时间轴 健康管理类报告页 时间轴节点 = 日期 + 类型徽章（测评 / 体检 / 门店养护）+ 关键指标摘要，学体检报告「记录归集与可视化」；家人档案入口在此页顶部露出（pkg-family 的家属代办是差异化优势，参考长辈就医「亲属代收代办」规范）。
会员等级与权益 卓旭会员中心 + 方向 C 夜色金 顶部等级徽章大卡（银 / 金 / 钻分级 + 成长值进度条）+ 权益清单逐条可读（不用图标墙）+ 积分 / 储值余额；A 级会员进入夜色金专属皮肤，形成「升级看得见」的视觉奖励。
我的 / 设置 河狸家我的页 头像 + 等级徽章 + 顾问入口（1 对 1 顾问是美业标配信任触点）；列表项图标 + 文字 + 右箭头，行高 ≥ 56px；「长辈模式」开关做成显眼的一等入口而非藏在三级设置里（适老规范：适老版入口必须固定且显著）。

4乐龄模式自查清单（工信部规范对照）

雪姬目标用户以乐龄女性为主，这份硬规范应作为 UI 验收标准。

  • 字号：乐龄模式正文 ≥ 18pt（现 elder 模式 body 17px 偏小，建议提到 19–20px）—— 工信部《APP 适老化通用设计规范》
  • 对比度：文本对比度 ≥ 4.5:1；状态不能只靠颜色区分，必须配文字标签（现有 --ink3 #767676 在 #f5f5f5 上约 4.4:1，临界，建议加深）
  • 触控：适老版主要组件热区 ≥ 60×60pt；按钮间距拉开防误触；现有 --btn-h 48px 在 elder 模式建议提到 ≥ 52px 并配合 padding 扩热区
  • 行距：段内行距 ≥ 1.3 倍、段间距 ≥ 行距 1.3 倍（现 1.6 行距达标）
  • 图标：金刚区 / tab 图标必须带文字标签，图标用具体形象不用抽象符号
  • 流程：预约、测评等主流程无弹窗干扰、无分支；每步可返回；关键节点支持语音播报
  • 文案：「查报告」优于「报告查询」，动词 + 大白话；避免「骨密度 T 值」这类裸术语，跟一句解释
  • 家属代办：pkg-family 邀请入口在适老版首页显著露出，子女可代约、代查、代收消息
  • 禁区：适老界面禁止广告插件与诱导按钮（合规红线）
